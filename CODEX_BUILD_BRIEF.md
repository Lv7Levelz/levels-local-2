# LEVELS LOCAL — CODEX BUILD BRIEF

## Purpose

You are working on the flagship website for **Levels Local**, a Sheffield-first web design and local business growth company.

The site must position Levels Local as a **premium, futuristic, conversion-focused local web partner** for small and medium-sized local businesses.

The brand promise is:
